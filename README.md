# rift v1

> collosseum hackathon
> deadline for spec below: 27th march

## product specs:

> creator platform with focus on increasing distribution and revenue for onchain creators
>
> slightly longer: we're building a creator platform on solana which focuses on providing tools for creators to increasing their distribution and revenue via products like micropayments gated blogging, gated chats and membership gated services

#### creating:

- smooth onboarding and uploading experience ( easy import etc )
- intuitive feel for writer as well as the reader
- themes, basic settings ( greyed out future features )
- email newsletter + blog

#### distribution:

- farcaster frames with full customizability and inline reader
- mint nft and share to followers feed
- newsletter emails

#### revenue:

- micropayments gating blogs
- "content" other than blogs behind paywall ( copy bento and gumroad)
- paid thread like chat interface ( pay per thread - can be closed by either party )
- limited collectible nfts settings with min. cost and royalty ( users pay for mint )
